# Bambu Lab X2D 공용 프린터 웹 관리 시스템 설계서

> 구현 전 검토용 설계서. 제품의 MQTT 토픽, 인증 방식, 영상 프로토콜과 실제 사용량 필드는 X2D 실기 및 펌웨어에서 검증한 뒤 확정한다.

## [개요 및 설계 이유]

공용 X2D 프린터의 영상, 현재 출력, 출력 이력, 사용자별 필라멘트 사용량과 예약을 한 웹 화면에서 관리한다. 프론트엔드는 React, API와 프린터 어댑터는 Node.js, 영속 데이터는 MySQL로 구성하고 Docker Compose로 실행한다.

예약은 사용할 시간에 대한 일정이며 프린터를 원격 잠그거나 자동으로 출력을 시작하지 않는다. JWT 로그인이 있어야 예약할 수 있다. 관리자는 사용자 계정과 프린터 연결 정보를 관리하고 일반 사용자는 자신의 기록과 사용량을 확인한다. 초기 범위에는 출력 파일 전송·원격 제어를 포함하지 않는다.

## [논리 아키텍처]

React 브라우저는 같은 출처의 Node API와 통신한다. API는 MQTT 상태를 공통 프린터 상태로 변환하고 SSE로 브라우저에 전달하며, MySQL에는 사용자와 예약·실제 출력 기록을 저장한다. 카메라 영상은 MQTT와 별개인 영상 어댑터가 중계한다. 실기 검증 전에는 특정 영상 프로토콜을 전제하지 않는다.

DB 애플리케이션 테이블은 `users`, `print_records` 두 개다. `users`에는 로그인 ID, 표시 이름, 비밀번호 해시, 역할, 활성 여부와 토큰 버전을 둔다. `print_records`는 예약과 실제 출력을 함께 표현하며 사용자 ID, 예약 시작·종료 및 상태, 실제 시작·종료 및 상태, 작업 ID, 예상·실제 필라멘트량, 재료별 JSON 상세와 변경 근거를 저장한다. 예약 전용 테이블과 프린터 테이블은 만들지 않는다.

시간 구간은 시작 포함·종료 제외로 비교한다. 겹침 검사와 예약 생성을 한 트랜잭션 및 프린터별 DB 잠금 안에서 수행해 동시 예약을 막는다. MQTT가 사용자를 인증해 주지 않으므로 사용자가 예약에 다음 출력을 명시적으로 연결하고, 연결되지 않은 작업은 미지정으로 남긴다. 출력량은 예상값과 실제값을 구분하며 알 수 없으면 NULL로 저장한다.

## [인프라 아키텍처]

Docker Compose의 서비스는 React 정적 파일을 제공하는 Node 기반 프론트 컨테이너, Node.js API 컨테이너, MySQL 컨테이너다. 프론트에서 `/api`, SSE 및 영상 경로를 같은 출처로 프록시한다. 운영은 HTTPS를 사용하고 DB 및 프린터 포트를 인터넷에 공개하지 않는다. MySQL 데이터와 암호화된 프린터 설정은 별도 영속 볼륨에 저장하고 정기 백업한다.

## [사전 요구 사항]

- 고정 IP 또는 DHCP 예약이 설정된 X2D와 프린터 LAN에 접근 가능한 Docker 호스트
- Docker Engine/Desktop 및 Docker Compose, 지속 저장 공간, 시간 동기화
- 프린터 IP·이름·시리얼 및 LAN 인증 정보, 펌웨어 버전
- 운영 주소와 HTTPS 설정, 초기 관리자 계정, 백업 위치
- X2D에서 MQTT 접속·토픽·상태 필드·인증 권한 및 카메라 프로토콜을 각각 실기 검증

제조사 매뉴얼은 LAN Only와 Developer Mode를 안내하지만, 현재 펌웨어와 설치 환경에서 필요한 설정을 확인한다. 참조: [Bambu Lab X2D 공식 매뉴얼](https://csm.bblcdn.com/hub/7c58718aaa2e40edab56efb87419a96a.pdf).

## [핵심 환경 변수 (.env)]

예정 변수: `NODE_ENV`, `WEB_PORT`, `BACKEND_PORT`, `DB_HOST`, `DB_PORT`, `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `MYSQL_ROOT_PASSWORD`, `JWT_SECRET`, `JWT_ISSUER`, `JWT_AUDIENCE`, `JWT_TTL_SECONDS`, `COOKIE_SECURE`, `DISPLAY_TIMEZONE`, `BOOTSTRAP_ADMIN_LOGIN`, `BOOTSTRAP_ADMIN_PASSWORD`, `SETTINGS_ENCRYPTION_KEY`, `SETTINGS_PATH`, `PRINTER_NAME`, `PRINTER_HOST`, `PRINTER_SERIAL`, `PRINTER_ACCESS_CODE`, `MQTT_PORT`, `MQTT_USERNAME`, `MQTT_REPORT_TOPIC`, `MQTT_CA_PATH`, `CAMERA_SOURCE_URL`, `STATUS_STALE_SECONDS`, `RESERVATION_SLOT_MINUTES`, `RESERVATION_MAX_HOURS`, `RESERVATION_HORIZON_DAYS`, `JOB_LINK_WINDOW_MINUTES`, `LOG_LEVEL`.

`.env`는 Git에 올리지 않고 React 빌드에 비밀값을 넣지 않는다. 관리자 GUI 설정은 `.env`를 덮어쓰지 않으며, 암호화 키와 프린터 인증 정보는 별도로 보관한다.

## [사용자 관리]

역할은 `ADMIN`, `USER`다. 관리자는 계정을 발급·비활성화하고 권한을 관리한다. 공개 회원가입은 제공하지 않는다. 비밀번호는 Argon2id 해시로 저장한다. JWT는 `HttpOnly`, `Secure`, `SameSite=Lax` 쿠키로 전달하고 로그인 후 상태 변경 요청은 CSRF 토큰으로 검사한다. Origin 허용 목록은 사용하지 않는다. 사용자 활성 상태·역할·토큰 버전은 서버에서 검증한다. 사용자는 본인 기록만, 관리자는 전체 기록과 사용량을 조회·보정할 수 있다. 비로그인 화면은 개인정보와 카메라를 노출하지 않는다.

## [주요 API]

기본 경로는 `/api/v1`이다.

| API | 역할 | 기능 |
| --- | --- | --- |
| `POST /auth/login`, `POST /auth/logout`, `GET /auth/me`, `PATCH /auth/password` | 공개/로그인 | 로그인, 로그아웃, 사용자 확인, 비밀번호 변경 |
| `GET /printer/status`, `GET /events` | 공개/로그인 | 공개 범위의 프린터 상태와 SSE |
| `GET /camera/stream.m3u8`, `GET /camera/segments/:name` | 로그인 | 인증된 영상 중계 |
| `GET /reservations`, `POST /reservations`, `PATCH /reservations/:id`, `POST /reservations/:id/cancel` | 공개/본인/관리자 | 예약 조회·생성·수정·취소 |
| `POST /reservations/:id/arm`, `DELETE /reservations/:id/arm` | 본인/관리자 | 다음 작업을 예약에 연결 대기 |
| `GET /prints`, `GET /prints/:id`, `GET /users/me/prints`, `GET /users/me/usage` | 공개/본인/관리자 | 출력 기록과 개인 통계 |
| `/admin/users`, `/admin/usage`, `/admin/prints/:id` | 관리자 | 계정, 전체 통계, 사용자·사용량 보정 |
| `/admin/printer-settings`, `/admin/printer-settings/test` | 관리자 | 프린터 설정 조회·연결 테스트·저장 |

시간은 UTC에 정규화하며 화면은 Asia/Seoul로 표시한다. 예약 충돌은 HTTP 409, 인증 오류는 401/403으로 응답한다. 임의 URL 접근, 인증 정보 응답 노출, 프린터 연결 설정의 무단 변경을 차단한다.

## [웹 UI 가이드]

메인 화면은 좌측 상단 카메라, 좌측 하단 현재 출력 정보, 가운데 출력 기록, 우측 예약·개인 기록 이동 버튼의 3열 구조다. 화면 우측 상단의 관리자 설정 아이콘은 프린터 이름, IP/호스트, 시리얼, MQTT·영상 연결 정보를 변경하는 모달을 연다. 카메라와 프린터 상태, 연결 지연, 예약 상태는 서로 구분해 표시한다.

개인 기록 페이지는 기간별 출력 횟수, 성공·실패 건수, 예상·실제 필라멘트량, 미확인 작업과 기록 목록을 보여준다. 관리자는 사용자별 통계와 미지정 작업을 확인하고 수정 사유와 함께 보정한다. 모바일은 카메라, 현재 상태, 예약, 이력 순으로 세로 배치한다. 테마는 라이트·다크 전환을 지원하고 Bambu Lab Studio의 초록색 계열을 강조색으로 사용한다. 아이콘은 단순한 선형 스타일을 쓰고 카드와 버튼은 작은 반경으로 모서리를 둥글게 한다.
